# Rebuilding the analysis data

The repository includes the processed datasets required by the scripts in
`code/analysis/`. Rebuilding those datasets from the original sources is
optional and requires the third-party data described in `data/raw/`.

Open `code/replication.Rproj`, place the downloaded source files in the folder
structure specified by the README in each `data/raw/` subfolder, and run the
scripts below from `code/`. Shared paths are defined in `clean/paths.R`.
Temporary construction files are written to the ignored
`data/intermediate/.build/` directory. Final analysis inputs are written to
`data/intermediate/`.

## Required source data

- Historical Census of Agriculture files from ICPSR Study 35206
- USDA Cropland Data Layer rasters for 2008--2021
- PRISM monthly climate grids
- LANDFIRE elevation and slope rasters
- Newberry Library, NHGIS, and Census Bureau county boundaries
- The historical boll-weevil workbook
- County rail-distance data and Donaldson--Hornbeck market access data

Source links and expected filenames are provided in the corresponding
`data/raw/` README files. The raw data are not redistributed with this
repository.

## Reproducibility

A complete rebuild is computationally intensive, particularly the raster and
county-crosswalk stages. The tested software environment is recorded in
`software_versions.txt`. Machine-learning intermediates may vary slightly when
the XGBoost or spatial-library versions differ; the datasets distributed in
`data/intermediate/` are the reference inputs used to generate the paper's
figures and tables.

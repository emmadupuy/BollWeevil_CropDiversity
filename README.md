# Boll weevil and crop diversity: replication package

This repository contains the replication materials for *Local Crop Diversity Slows Pest Diffusion: Evidence from the Boll Weevil*, by Emma Du Puy and Marguerite Obolensky. Open `code/replication.Rproj` and run the individual scripts in `code/analysis/` to reproduce the paper’s figures and tables; these scripts use the supplied processed data in `data/intermediate/` and, where indicated in the scripts, source files placed locally in `data/raw/`, and they save the finished files in `output/figures/` and `output/tables/`. The scripts in `code/clean/` document the data cleaning and construction used for the project, but the underlying third-party raw data are not redistributed; each `data/raw/` subfolder contains the relevant source link and download instructions.

# Transportation and market access

**Market access source:** Dave Donaldson and Richard Hornbeck, [“Railroads and American Economic Growth: A Market Access Approach”](https://doi.org/10.1093/qje/qjw002), *Quarterly Journal of Economics* 131(2), 2016, with the [authors’ replication archive](https://www.dropbox.com/s/iys8bsu2ygt4lvu/Railroads%20DH%20Oct2015%20ReplicationFiles.rar?dl=1). Place the recovered `market_access.csv.gz` in this folder. Market access is used as the additional control in column 3 of Table 2, in both the IV regression and its first stage.

**Other transportation sources:** The rail workflow starts from the authors’ county-centroid rail-distance export `gee_county_centroid_rail_distance.csv` and historical county boundaries, then creates `raildata.rds`; the upstream rail-network source still needs to be documented. Rail distance is used in column 2 of Table 2. The historical highway scripts use Baum-Snow Form 500 data, an interstate-highway shapefile, the 2000 county shapefile, and a state FIPS/ICPSR crosswalk, but highway distance is not used by any retained paper specification and is not part of the required rebuild. These raw files are not redistributed here.

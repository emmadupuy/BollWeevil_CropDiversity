# PRISM climate data

**Source:** PRISM Climate Group, Oregon State University, [PRISM data portal](https://prism.oregonstate.edu/). The historical workflow uses monthly 4 km grids for precipitation, minimum temperature, maximum temperature, dew-point temperature, and minimum and maximum vapor-pressure deficit. Model training uses 2008–2020, validation uses 2021, and the regression analysis uses county-level historical precipitation and temperature summaries. Preserve product names, versions, download dates, and metadata. The original grids are not redistributed here.

# Historical agricultural census

**Source:** Haines, Michael R., Price V. Fishback, and Paul W. Rhode, ICPSR Study 35206. Download version 4 in Stata format from [ICPSR](https://www.icpsr.umich.edu/web/ICPSR/studies/35206) and preserve its `DSxxxx` directory structure under this folder. The cleaning scripts use these county-level agricultural censuses to construct the historical crop-diversity panels used throughout the paper. Access may require an ICPSR account or institutional affiliation; the source files are not redistributed here.
